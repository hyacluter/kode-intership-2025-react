## Декомпозиция задания

1. Инициализация проекта Vite + React + TypeScript.
2. Настройка роутинга (React Router): главная страница и страница деталей.
3. Настройка Axios и типов данных для API.
4. Создание констант департаментов и утилит сортировки/фильтрации.
5. Реализация хука useSessionState для сохранения фильтров.
6. Вёрстка Top Bar: поиск, кнопка сортировки, вкладки.
7. Вёрстка списка пользователей (UserCard) и экрана загрузки/ошибки.
8. Реализация модального окна сортировки.
9. Реализация главной страницы: загрузка, фильтрация, сортировка, группировка по году.
10. Реализация страницы деталей пользователя по маршруту /user/:id.
11. Адаптивные стили через styled-components.
12. Финальная проверка и пуш в main.
